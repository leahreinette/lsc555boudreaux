Assignment #1: System Evaluation

System overview

The Los Angeles Public Library serves the largest metropolitan population of any public library system in the United States (~19 million residents served across 72 branches.)

The library system's website is both robust in the amount of information it contains and its accessibility--which befits the large and diverse population it serves. For example, many features of the website are accessible in 15 different languages.

A unique feature of the website is that there is one search box, but with two side by side search buttons that enables patrons to choose whether they want to search the library's catalog or their website.

The website is aesthetically pleasing and reflects the geography and community it serves. The underlying colors are earth tones, which make the user think of Los Angeles's semi-arid climate. The website uses colorful images to contrast with the background that reflect the diversity of Los Angeles's population and the types of programs and events the library offers.

Users

The primary potential users are the 19 million residents of the greater Los Angeles area. A note that LAPL offers any resident of California a library card, extending the potential user base to ~39 million residents.

Content

The webpage is a portal to a massive amount of content including the library catalog, as well as information on locations and events. A standout features is information on services which includes library specific support for:

  • youth
  • unhoused patrons
  • new Americans
  • returning citizens
  • veterans
  • English language learners

There are also features that enable you to chat live with a librarian or make an appointment with a librarian.

The only "con" I'd note about the website is some of the accessibility features the library offers (ex: interpreting services, TTY, etc.) are not featured as prominently on the website as information about language access is. I'd recommend highlighting the inclusive features they provide more prominently on the home page.
